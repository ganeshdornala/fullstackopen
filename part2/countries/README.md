# Countries

A React application built as part of the University of Helsinki Full Stack Open course.

## Exercises

- **2.18:** Search countries and display country information.
- **2.19:** Select a country from the search results using a Show button.
- **2.20:** Display current weather information for the selected country's capital.

## Features

- Search countries by name.
- Display country capital, area, languages, and flag.
- Handle multiple search results and country selection.
- Fetch capital weather using the OpenWeatherMap API.
- Display temperature, weather description, icon, and wind speed.
- Handle loading states and API errors.

## Technologies

- React
- JavaScript
- Vite
- Fetch API
- OpenWeatherMap API
