# Courseinfo (Part 2)

A course information application built with React as part of the University of Helsinki Full Stack Open course.

## Exercises

- **2.1:** Create a `Course` component that renders the course name and its parts.
- **2.2:** Display the total number of exercises in the course.
- **2.3:** Calculate the total using the array method `reduce`.
- **2.4:** Support an arbitrary number of courses.
- **2.5:** Move the `Course` component into a separate module (`src/components/Course.jsx`).

## Concepts Practiced

- Rendering collections with `map`
- Using `key` props in lists
- Array method `reduce`
- Component composition
- Separate modules and imports/exports

## Run Locally

```bash
npm install
npm run dev
```
