# Exercise 0.4: New note

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User types a note and clicks Save
    browser->>server: POST /exampleapp/new_note (form data: note)
    activate server
    Note over server: Create note with content and timestamp
    Note over server: Add note to the in-memory notes list
    server-->>browser: HTTP 302 Redirect (Location: /exampleapp/notes)
    deactivate server

    browser->>server: GET /exampleapp/notes
    activate server
    server-->>browser: HTML document
    deactivate server

    browser->>server: GET /exampleapp/main.css
    server-->>browser: CSS file
    browser->>server: GET /exampleapp/main.js
    server-->>browser: JavaScript file

    Note over browser: Browser reloads the page and executes main.js
    browser->>server: GET /exampleapp/data.json
    activate server
    server-->>browser: JSON array containing the notes, including the new note
    deactivate server
    Note over browser: JavaScript creates the notes list in the DOM and displays it
```

The traditional form submission causes a page reload. The server responds to the POST with a redirect, and the browser then requests the notes page and its resources again.
