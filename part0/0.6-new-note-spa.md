# Exercise 0.6: New note in the single-page app

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User types a note and clicks Save
    Note over browser: spa.js submit handler calls preventDefault()
    Note over browser: Create note object containing content and timestamp
    Note over browser: Add note to local notes list and redraw the list immediately

    browser->>server: POST /exampleapp/new_note_spa (JSON; Content-Type: application/json)
    activate server
    Note over server: Parse request and save the new note
    server-->>browser: HTTP 201 Created (JSON response: note created)
    deactivate server

    Note over browser: Handle/log the response; no redirect or page reload
```

The SPA prevents the form's default page reload. It updates the browser's view and sends the new note to the server as JSON in a single POST request.
