# Exercise 0.6: New note in the single-page app

```mermaid
sequenceDiagram
    participant browser
    participant server

    Note over browser: User types a note and clicks Save
    Note over browser: JavaScript prevents the default form submission
    Note over browser: Create a note object with content and timestamp
    Note over browser: Add the note to the local list and redraw the list

    browser->>server: POST /exampleapp/new_note_spa
    Note right of browser: The request body contains JSON
    activate server
    Note over server: Save the new note
    server-->>browser: HTTP 201 Created
    deactivate server

    Note over browser: The page stays open without a reload
```

The single-page app prevents the form's default submission. It adds the note to the page immediately and sends the note to the server as JSON in one POST request. The server saves the note and responds with HTTP 201 Created. The browser does not navigate to a new page.
