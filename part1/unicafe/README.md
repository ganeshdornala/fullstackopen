# Unicafe

A feedback application built with React as part of the University of Helsinki Full Stack Open course.

## Exercises

- **1.6:** Collect feedback using buttons and React state.
- **1.7:** Calculate average and positive feedback statistics.
- **1.8:** Extract statistics into a reusable component.
- **1.9:** Conditionally display statistics when feedback is available.
- **1.10:** Create reusable components for buttons and statistic lines.
- **1.11:** Display statistics using an HTML table.

## Concepts Practiced

- React components and props
- `useState` hook
- Event handling
- Derived data and calculations
- Conditional rendering
- Component composition
- Rendering tabular data
