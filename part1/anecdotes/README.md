# Anecdotes

An application for displaying programming anecdotes, collecting votes, and identifying the anecdote with the most votes.

Built with React as part of the University of Helsinki Full Stack Open course.

## Exercises

- **1.12:** Display a random anecdote when the user requests the next one.
- **1.13:** Allow users to vote for the displayed anecdote.
- **1.14:** Display the anecdote with the highest number of votes.

## Concepts Practiced

- React components
- `useState` hook
- Event handling
- Working with arrays
- Immutable state updates
- Random number generation
- Array methods and computed values
- Rendering dynamic data
